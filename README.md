## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or Bun
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/NaveenEkanayake/My-New-Portfolio.git

# Navigate to project
cd My-New-Portfolio

# Install dependencies
npm install
# or: bun install

# Start development server
npm run dev
# or: bun run dev
```

Available scripts:
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build

### Development

The project uses TypeScript with strict mode. All components are in `src/`:

- `src/components/` - React UI components
- `src/components/three/` - Three.js visualizations
- `src/data/portfolio.ts` - All portfolio data
- `src/main.tsx` - Entry point

## 📦 Deployment

### Vercel (Recommended)

This project is configured for Vercel with `vercel.json`:

```bash
vercel
# or connect your GitHub repo to Vercel for automatic deploys
```

The build command is `npm run build` which runs `tsc --noEmit && vite build`.

### Other Platforms

- **Netlify**: Drag-and-drop the `dist/` folder or connect to GitHub
- **Cloudflare Pages**: Configure build command as `npm run build`
- **Traditional hosting**: Upload `dist/` contents to your web server
